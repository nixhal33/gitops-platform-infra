This project ships a real microservices app (Google's Online Boutique) end to end. Terraform provisions the AWS infrastructure from reusable modules (networking, compute, security) with remote state and separate staging and prod environments. GitHub Actions lints, tests, scans (Trivy), builds and pushes images, then updates a separate GitOps repo. ArgoCD syncs that repo to a Kubernetes cluster, so every deploy is a git commit. Prometheus and Grafana track error rate and latency, with prioritized alerts and one automated remediation. Failures are induced on purpose and documented in postmortems.
